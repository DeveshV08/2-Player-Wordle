# 2-Player-Wordle

Problem Statement: Traditional Wordle is primarily a single-player game, it does not provide a built-in way for two friends to challenge each other using custom words and word lengths.

Project Goal: My project is to develop a two-player, command-line Wordle game in Java, where players take turns selecting secret words and guessing their opponent's word.

MVP Scope: 
- Implement 2-player Wordle with custom secret words and word lengths.
- Develop accurate letter feedback.
- Implement a six attempt limit and win/loss detection.

Chunked Build Plan: 
1. Set up the Java project and GitHub repository in IntelliJ
2. Implement secret word selection
3. Implement the guessing system
4. Implement letter-matching logic to determine which letters are in the correct location.
5. Add proper feedback
6. Implement win/loss detection
7. Add automatic role switching after each round
8. Update the scoreboard after each round

Tech Stack:
- Language: Java
- External tools: Dictionary API, GitHub
- libraries: ArrayList, Random
- Storing Data: Text files

Future Plans: 
- Convert it into a GUI
- Add animations and special effects.
- Implement a points system based on number of guesses.
